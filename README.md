# Pranjal Studio — MERN portfolio

TypeScript MERN app with MVC on the API:

- **Model** — Mongoose schemas (`Contact`, `Project`, `Plan`)
- **View** — React + Vite frontend
- **Controller** — Express controllers + routes under `/api`

## Run

```bash
npm run install:all
npm run dev
```

- Client: http://localhost:5173
- API: http://localhost:5050/api/health

MongoDB is optional. If it is not running, the server uses an in-memory store so pages still load.
